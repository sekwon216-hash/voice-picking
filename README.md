# 보이스 피킹

물류센터 피킹지시서를 읽어 두고, 무선이어폰 재생 버튼을 누를 때마다 다음 상품과 박스 수를 음성으로 안내하는 안드로이드 앱입니다. 화면을 꺼도 동작합니다.

## 설치

휴대폰에서 아래 주소를 열면 최신 APK가 내려받아집니다.

https://github.com/sekwon216-hash/voice-picking/releases/latest/download/voice-picking.apk

## 이어폰 버튼

- 한 번: 완료하고 다음 상품
- 두 번: 다시 듣기 (설정에서 '다음'으로 바꿀 수 있음)
- 세 번: 이전 상품으로

## 새 피킹지

claude.ai의 보이스 피킹 페이지에서 사진을 읽힌 뒤 '단독 앱용 데이터 복사'를 누르고, 앱의 피킹지 탭에서 붙여넣습니다.

`keystore/app.jks`는 업데이트가 기존 설치 위에 덮어써지도록 고정한 개인용 서명 키입니다.
